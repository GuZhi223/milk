# Persona 目录

此目录存放人格特征数据，按聊天对象组织。

## 目录结构

```
persona/
├── {partner-name}/          # 按聊天对象名称组织
│   ├── persona.md          # 人格特征数据
│   └── versions/           # 历史版本
│       └── persona_v1.md
└── README.md
```

## 数据格式

人格特征数据包含5层结构：
1. **硬规则** - 不可违背的核心特征
2. **身份** - 基本信息、关系定位
3. **说话风格** - 语言习惯、表达方式
4. **情感模式** - 情绪反应、依恋类型
5. **关系行为** - 互动模式、边界感

## 使用方式

由persona-manager.js模块管理，用于构建AI对话的系统提示词。
