## 用户需求

优化AI辅助创建对话伙伴的功能，参考ex-skill项目的设计理念。

## 核心功能

1. **丰富标签系统**：在人格数据结构中增加爱的语言、星座、MBTI、性格标签等维度，使对话伙伴的人格刻画更加立体和精确
2. **实现对话纠正机制**：允许用户在对话过程中纠正AI的表现（如"ta不会这样说"），纠正内容写入专用层并立即生效
3. **支持增量记忆追加**：创建对话伙伴后，用户可随时补充新的记忆和人格信息，系统自动合并到已有数据中

## 功能细节

- 爱的语言包括：肯定的言辞、精心的时刻、接受礼物、服务的行动、身体的接触
- 星座支持十二星座
- MBTI支持16种人格类型
- 性格标签包括：话痨、闷骚、嘴硬心软、冷暴力、粘人、独立等
- 对话纠正记录与人格数据分离存储，优先级最高
- 增量记忆支持从新聊天记录中自动提取并合并

## 技术栈

- 前端框架：原生JavaScript（与现有项目一致）
- 存储：localStorage（与现有项目一致）
- AI服务：复用现有AIService模块

## 实现方案

### 架构设计

采用与现有项目一致的模块化设计，通过IIFE模式封装各模块，暴露全局接口。数据流遵循现有模式：用户输入 -> 数据处理 -> localStorage存储 -> 提示词生成。

### 核心修改

#### 1. persona-manager.js - 扩展人格数据结构

在DEFAULT_PERSONA中新增标签相关字段：

```javascript
persona_tags: {
    love_languages: [],      // 爱的语言
    zodiac: '',              // 星座
    mbti: '',                // MBTI类型
    personality_tags: []     // 性格标签
}
```

#### 2. skill-builder.js - 增加纠正层支持

在Skill数据结构中增加corrections字段：

```javascript
{
    corrections: [],  // 纠正记录数组
    // 每条记录格式：
    {
        timestamp: ISO时间戳,
        original_response: AI原回复,
        corrected_response: 用户纠正后的内容,
        context: 纠正时的上下文
    }
}
```

#### 3. memory-manager.js - 增加增量追加功能

新增appendMemory函数，支持合并新记忆到已有维度中，对数组字段进行去重合并。

#### 4. ai-analyzer.js - 更新分析提示词

在人格分析提示词中增加对新标签维度的提取要求。

#### 5. conversation-intake.js - 扩展录入流程

增加可选的标签收集步骤，或在确认页面展示标签编辑入口。

### 性能考量

- 纠正记录限制数量（最多50条），避免存储膨胀
- 增量记忆合并使用Set去重，O(n)时间复杂度
- 标签数据采用预定义选项，避免自由文本输入导致的数据不一致

### 兼容性

- 所有新增字段采用可选设计，不影响已有对话伙伴的正常使用
- generateSystemPrompt函数需兼容新旧数据格式
