# Memory 目录

此目录存放关系记忆数据，按聊天对象组织。

## 目录结构

```
memory/
├── {partner-name}/          # 按聊天对象名称组织
│   ├── memory.md           # 关系记忆数据
│   └── versions/           # 历史版本
│       └── memory_v1.md
└── README.md
```

## 数据格式

关系记忆数据包含8个维度：
1. 关系时间线
2. 日常模式
3. 共同经历
4. 饮食偏好
5. 兴趣爱好
6. 争吵模式
7. 甜蜜瞬间
8. 分手相关（如适用）

## 使用方式

由memory-manager.js模块管理，支持增量更新和版本控制。
