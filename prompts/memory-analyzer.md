# 关系记忆分析模板

## 概述

这是一个用于从聊天记录中提取关系记忆的分析模板。通过分析聊天内容，提取8个维度的关系记忆：时间线、日常模式、共同经历、饮食偏好、兴趣爱好、争吵模式、甜蜜瞬间、分手相关。

## 分析维度

### 1. 关系时间线（Timeline）

**分析目标：** 提取关系发展的关键时间点。

**提取内容：**
- **初次相遇**：认识的时间、地点、方式
- **第一次约会**：第一次约会的时间、地点、活动
- **确定关系**：正式确定关系的时间
- **重要里程碑**：关系中的重要事件
- **分手时间**：分手的时间（如适用）
- **分手原因**：分手的主要原因（如适用）

**分析方法：**
- 识别时间相关的关键词（"第一次"、"记得那天"、"去年"等）
- 分析事件描述中的时间线索
- 注意关系状态变化的节点
- 从上下文推断时间顺序

**输出格式：**
```json
{
  "first_met": "2022-09-01",
  "first_date": "2022-09-15",
  "relationship_start": "2022-10-01",
  "important_milestones": [
    {"date": "2023-02-14", "event": "第一次一起过情人节"},
    {"date": "2023-08-15", "event": "第一次一起旅行"}
  ],
  "breakup_date": null,
  "breakup_reason": null
}
```

### 2. 日常模式（Daily Patterns）

**分析目标：** 提取关系中的日常互动模式。

**提取内容：**
- **联系频率**：每天联系几次、谁更主动
- **聊天时间**：通常在什么时间聊天
- **约会频率**：多久见一次面
- **约会计划**：通常做什么、去哪里
- **日常活动**：一起做的日常事情

**分析方法：**
- 统计消息发送时间分布
- 分析谁更主动发起对话
- 识别约会相关的关键词
- 注意日常活动的描述

**输出格式：**
```json
{
  "contact_frequency": "每天多次",
  "initiator": "双方轮流，对方更主动",
  "chat_time_preference": "晚上睡前",
  "date_frequency": "每周1-2次",
  "date_plans": ["看电影", "吃饭", "逛街"],
  "routine_activities": ["一起吃饭", "一起学习", "一起散步"]
}
```

### 3. 共同经历（Shared Experiences）

**分析目标：** 提取一起经历过的重要事件。

**提取内容：**
- **去过的地方**：一起旅行、游玩的地方
- **做过的事情**：一起完成的活动、项目
- **旅行经历**：一起旅行的详细经历
- **内部笑话**：只有你们懂的笑话、暗号
- **难忘事件**：印象深刻的重要事件

**分析方法：**
- 识别地点、活动相关的关键词
- 分析事件描述的详细程度
- 注意重复提及的经历
- 识别只有两人懂的特殊表达

**输出格式：**
```json
{
  "places_visited": ["北京故宫", "上海外滩", "杭州西湖"],
  "activities_done": ["一起做饭", "一起看电影", "一起运动"],
  "trips_together": [
    {"destination": "三亚", "time": "2023年暑假", "highlights": ["海边看日出", "吃海鲜"]}
  ],
  "inside_jokes": ["那个下雨天的笑话", "小猪佩奇的梗"],
  "memorable_events": ["第一次一起过生日", "一起看流星雨"]
}
```

### 4. 饮食偏好（Food Preferences）

**分析目标：** 提取饮食相关的偏好和习惯。

**提取内容：**
- **喜欢的食物**：对方喜欢吃的食物
- **不喜欢的食物**：对方不喜欢吃的食物
- **喜欢的餐厅**：经常去的餐厅
- **用餐习惯**：吃饭时的习惯、偏好
- **一起做饭**：一起做饭的经历

**分析方法：**
- 识别食物相关的关键词
- 分析餐厅、外卖相关的对话
- 注意饮食偏好的表达
- 识别一起用餐的描述

**输出格式：**
```json
{
  "favorite_foods": ["火锅", "奶茶", "草莓"],
  "disliked_foods": ["香菜", "苦瓜"],
  "favorite_restaurants": ["海底捞", "星巴克"],
  "dining_habits": ["喜欢尝试新餐厅", "吃饭时喜欢聊天"],
  "cooking_together": ["一起做过蛋糕", "一起煮过火锅"]
}
```

### 5. 兴趣爱好（Interests）

**分析目标：** 提取个人和共同的兴趣爱好。

**提取内容：**
- **个人爱好**：对方自己的兴趣爱好
- **共同爱好**：两人共同的兴趣爱好
- **喜欢的音乐**：喜欢的音乐类型、歌手
- **喜欢的电影**：喜欢的电影类型、具体电影
- **喜欢的书籍**：喜欢的书籍类型、具体书籍
- **分享的内容**：经常分享的内容类型

**分析方法：**
- 识别兴趣爱好相关的关键词
- 分析分享内容的类型
- 注意娱乐活动的描述
- 识别文化消费的偏好

**输出格式：**
```json
{
  "personal_hobbies": ["摄影", "画画", "弹吉他"],
  "shared_hobbies": ["看电影", "旅行", "美食"],
  "favorite_music": ["周杰伦", "Taylor Swift", "轻音乐"],
  "favorite_movies": ["爱情片", "喜剧片", "科幻片"],
  "favorite_books": ["小说", "心理学", "旅行文学"],
  "shared_content": ["搞笑视频", "美食照片", "旅行攻略"]
}
```

### 6. 争吵模式（Argument Patterns）

**分析目标：** 提取冲突处理模式。

**提取内容：**
- **常见原因**：经常因为什么吵架
- **反应模式**：吵架时的行为表现
- **和好方式**：通常如何和好
- **触发点**：容易引发冲突的事情
- **学到的教训**：从冲突中学到的东西

**分析方法：**
- 识别冲突相关的关键词
- 分析争吵前后的对话模式
- 注意和好过程的描述
- 识别反复出现的冲突主题

**输出格式：**
```json
{
  "common_causes": ["误会", "忙碌忽视", "意见不合"],
  "reaction_patterns": ["会沉默", "会哭泣", "会解释"],
  "resolution_methods": ["主动道歉", "沟通解释", "给对方空间"],
  "triggers": ["被忽视", "承诺未兑现", "与异性接触"],
  "lessons_learned": ["要及时沟通", "要互相理解", "要给对方空间"]
}
```

### 7. 甜蜜瞬间（Sweet Moments）

**分析目标：** 提取关系中的美好时刻。

**提取内容：**
- **心动时刻**：让人心动的瞬间
- **表达爱意**：表达爱意的方式
- **小甜蜜**：日常中的小甜蜜
- **惊喜**：给对方的惊喜
- **亲昵行为**：亲密的举动、称呼

**分析方法：**
- 识别情感表达的关键词
- 分析亲密互动的描述
- 注意浪漫、温馨的时刻
- 识别特殊称呼、暗号

**输出格式：**
```json
{
  "heartwarming_times": ["第一次牵手", "第一次说我爱你", "雨天共撑一把伞"],
  "love_expressions": ["说'爱你'", "写小作文", "送小礼物"],
  "small_gestures": ["早安晚安", "记住喜好", "关心健康"],
  "surprises": ["生日惊喜", "节日礼物", "突然出现"],
  "affectionate_behaviors": ["叫昵称", "牵手", "拥抱"]
}
```

### 8. 分手相关（Breakup Related）

**分析目标：** 提取分手相关的记忆（如适用）。

**提取内容：**
- **最后对话**：分手前后的对话
- **未说出口的话**：想说但没说的话
- **遗憾**：关系中的遗憾
- **Closure**：是否得到closure
- **学到的教训**：从关系中学到的教训

**分析方法：**
- 识别分手相关的关键词
- 分析分手前后的对话模式
- 注意遗憾、后悔的表达
- 识别成长、反思的内容

**输出格式：**
```json
{
  "final_conversations": ["最后那次争吵", "分手的对话"],
  "unsaid_words": ["其实我一直...", "如果当时..."],
  "regrets": ["没有更珍惜", "没有好好沟通"],
  "closure_achieved": false,
  "lessons_learned": ["要珍惜眼前人", "要及时沟通"]
}
```

## 分析流程

### 第一步：数据预处理

1. **时间排序**：按时间顺序排列消息
2. **对话分组**：将连续对话分成有意义的片段
3. **主题标记**：为每个片段标记主题

### 第二步：特征提取

1. **关键词识别**：识别各维度的关键词
2. **模式识别**：识别重复出现的模式
3. **情境分析**：分析不同情境下的行为

### 第三步：记忆构建

1. **维度填充**：按8个维度组织记忆
2. **时间关联**：将事件与时间关联
3. **重要性评估**：评估每个记忆的重要性

### 第四步：输出生成

1. **结构化输出**：生成JSON格式的记忆数据
2. **时间线生成**：生成关系时间线
3. **摘要生成**：生成可读的记忆摘要

## 质量保证

### 准确性保证

1. **时间准确**：尽量准确推断时间
2. **事实准确**：基于聊天记录，而非推测
3. **上下文准确**：考虑对话上下文

### 完整性保证

1. **维度覆盖**：确保8个维度都有数据
2. **时间覆盖**：覆盖关系发展的各个阶段
3. **事件覆盖**：覆盖重要和日常事件

### 平衡性保证

1. **好坏平衡**：既记录美好，也记录冲突
2. **日常特殊平衡**：既记录日常，也记录特殊
3. **细节概括平衡**：既有细节，也有概括

## 输出格式

最终输出一个完整的关系记忆JSON对象，包含8个维度的详细数据，可以用于丰富AI对话的记忆内容。
