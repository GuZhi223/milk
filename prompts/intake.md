# 对话式信息录入模板

## 概述

这是一个用于收集用户关于聊天对象信息的对话式引导模板。通过友好的对话流程，逐步收集必要信息，为后续的人格分析和关系记忆提取奠定基础。

## 对话流程

### 第一步：基础信息收集

**开场白：**
"你好！我将帮助你创建一个专属的AI对话伙伴。让我们从一些基础信息开始，只需要3个简单的问题。"

**问题1：对方的称呼（必填）**
"首先，请告诉我你想要创建的AI对话伙伴的称呼是什么？可以是昵称、外号或者任何你喜欢的称呼。"

**解析规则：**
- 字段名：`partner_name`
- 必填：是
- 验证：非空，长度不超过20字符

**问题2：基本信息（可选）**
"接下来，你可以用一句话简单介绍一下对方。比如：'25岁，程序员，在北京工作'或者'大学同学，喜欢旅行和摄影'。如果暂时不想说，直接跳过也可以。"

**解析规则：**
- 字段名：`basic_info`
- 必填：否
- 提取维度：年龄、职业、所在地、认识方式、关系状态

**问题3：性格印象（可选）**
"最后，用一句话描述你对对方的性格印象。比如：'温柔体贴，但有时候会固执'或者'活泼开朗，喜欢开玩笑'。同样可以跳过。"

**解析规则：**
- 字段名：`personality_impression`
- 必填：否
- 提取维度：性格特点、说话风格、情感表达方式

### 第二步：确认信息

**汇总确认：**
"好的，让我确认一下我了解到的信息：
- 称呼：{partner_name}
- 基本信息：{basic_info}
- 性格印象：{personality_impression}

这些信息正确吗？如果需要修改，请告诉我哪里需要调整。"

### 第三步：引导下一步

**引导语：**
"太好了！现在我们已经有了基础信息。接下来，你可以：
1. **导入聊天记录** - 从微信、QQ等平台导入聊天记录，让我更深入地了解对方
2. **手动补充信息** - 直接告诉我更多关于对方的细节
3. **开始对话** - 基于现有信息创建AI对话伙伴

你想要先进行哪一步？"

## 交互设计原则

1. **渐进式引导**：从简单问题开始，逐步深入
2. **降低压力**：除称呼外，其他信息都可以跳过
3. **提供示例**：每个问题都附带具体示例，帮助用户理解
4. **确认环节**：在收集完信息后，让用户确认，确保准确性
5. **清晰选择**：在每一步结束时，提供明确的下一步选项

## 数据处理逻辑

### 输入解析

用户输入应该被解析为以下结构：

```json
{
  "partner_name": "小可爱",
  "basic_info": {
    "age": "25",
    "occupation": "程序员",
    "location": "北京",
    "how_met": "大学同学",
    "relationship_status": "恋爱中"
  },
  "personality_impression": {
    "traits": ["温柔", "体贴", "偶尔固执"],
    "speaking_style": "说话轻声细语",
    "emotional_expression": "善于表达情感"
  }
}
```

### 验证规则

1. **partner_name**：必填，长度1-20字符
2. **basic_info**：可选，如果提供，至少包含一个维度
3. **personality_impression**：可选，如果提供，至少包含一个维度

### 错误处理

- 如果用户输入无效，友好地提示重新输入
- 如果用户想要跳过，确认后继续下一步
- 如果用户想要修改，允许返回上一步

## 输出格式

收集完成后，输出一个结构化的JSON对象，包含所有收集到的信息，供后续分析模块使用。
