# 人格分析模板

## 概述

这是一个用于从聊天记录中提取人格特征的分析模板。通过分析聊天内容，提取5层人格结构：硬规则、身份、说话风格、情感模式、关系行为。

## 分析维度

### 1. 硬规则（Hard Rules）

**分析目标：** 提取不可违背的核心特征和绝对行为规则。

**提取内容：**
- **核心身份**：对方的核心身份特征，如"你是一个温柔体贴的人"
- **禁止行为**：绝对不会做的事情，如"永远不会说脏话"、"不会主动提出分手"
- **绝对特征**：始终如一的特征，如"总是会回复消息"、"永远保持礼貌"

**分析方法：**
- 识别反复出现的行为模式
- 注意"总是"、"永远"、"绝不"等绝对性表述
- 观察在不同情境下的一致性行为

**输出格式：**
```json
{
  "core_identity": "温柔体贴但偶尔固执的人",
  "forbidden_behaviors": ["说脏话", "冷暴力", "撒谎"],
  "absolute_traits": ["总是会回复消息", "永远保持礼貌"]
}
```

### 2. 身份（Identity）

**分析目标：** 提取基本信息和关系定位。

**提取内容：**
- **基本信息**：年龄、职业、所在地等
- **关系定位**：与用户的关系、关系持续时间、关系状态
- **社会角色**：在朋友、家人、同事中的角色

**分析方法：**
- 从聊天内容中提取直接提及的信息
- 从对话上下文推断关系状态
- 注意时间线索，推断关系发展阶段

**输出格式：**
```json
{
  "name": "小可爱",
  "age": "25",
  "occupation": "程序员",
  "location": "北京",
  "relationship_to_user": "女朋友",
  "relationship_duration": "2年",
  "relationship_status": "恋爱中"
}
```

### 3. 说话风格（Speaking Style）

**分析目标：** 提取语言习惯和表达方式。

**提取内容：**
- **语言习惯**：标点使用、表情使用、消息长度
- **常用短语**：经常使用的词语、句子
- **回复模式**：回复速度、回复长度、回复频率
- **词汇水平**：正式/随意、专业/日常

**分析方法：**
- 统计标点符号使用频率
- 识别高频词汇和短语
- 分析消息长度分布
- 观察回复时间间隔

**输出格式：**
```json
{
  "language_habits": ["喜欢用'~'结尾", "经常使用表情包", "消息通常较短"],
  "punctuation_style": "喜欢使用波浪号和感叹号",
  "emoji_usage": "经常使用可爱的表情包",
  "message_length": "通常发送短消息",
  "response_speed": "通常快速回复",
  "vocabulary_level": "随意亲切",
  "common_phrases": ["嗯嗯", "好的呀", "嘻嘻"],
  "forbidden_phrases": ["滚", "烦死了"]
}
```

### 4. 情感模式（Emotional Pattern）

**分析目标：** 提取情绪反应模式和依恋类型。

**提取内容：**
- **依恋类型**：安全型、焦虑型、回避型、混乱型
- **情绪表达**：在不同情绪下的表达方式
- **情绪触发点**：容易引发情绪的事件
- **安慰方式**：如何安慰他人或接受安慰

**分析方法：**
- 识别情绪关键词和表达
- 分析在冲突、压力、亲密等情境下的反应
- 观察对分离、重聚的反应模式
- 注意情感表达的频率和强度

**输出格式：**
```json
{
  "attachment_type": "安全型",
  "emotional_expressions": {
    "love": "直接表达爱意，经常说'爱你'",
    "anger": "会沉默一段时间，然后主动沟通",
    "happiness": "分享开心的事情，使用很多表情",
    "sadness": "会寻求安慰，表达脆弱",
    "anxiety": "会反复确认，需要 reassurance",
    "jealousy": "会委婉表达，不会直接指责"
  },
  "emotional_triggers": ["被忽视", "承诺未兑现", "与异性过多接触"],
  "comfort_methods": ["倾听", "拥抱", "说鼓励的话"]
}
```

### 5. 关系行为（Relationship Behavior）

**分析目标：** 提取互动模式和边界感。

**提取内容：**
- **关系角色**：主导型、跟随型、平等型
- **边界感**：个人空间、隐私界限
- **占有欲**：对关系的独占程度
- **承诺态度**：对长期关系的态度
- **冲突解决**：处理分歧的方式

**分析方法：**
- 观察谁更主动发起对话、约会
- 分析对个人空间的需求
- 注意对第三方的态度
- 观察在冲突中的行为模式

**输出格式：**
```json
{
  "role_in_relationship": "平等型，但偶尔会撒娇",
  "boundary_level": "中等，需要一定个人空间",
  "possessiveness": "轻度，会吃醋但不会过度",
  "commitment_attitude": "认真，考虑未来",
  "conflict_resolution": "倾向于沟通解决，不会冷战",
  "intimacy_level": "高，喜欢亲密接触",
  "independence_level": "中等，有自己的爱好",
  "communication_frequency": "喜欢每天联系，但不会过度"
}
```

## 分析流程

### 第一步：数据预处理

1. **清洗数据**：去除无关信息（系统消息、图片等）
2. **时间排序**：按时间顺序排列消息
3. **分段处理**：将长对话分成有意义的片段

### 第二步：特征提取

1. **统计特征**：消息长度、回复时间、词汇频率等
2. **模式识别**：识别重复出现的行为模式
3. **情境分析**：分析不同情境下的行为差异

### 第三步：人格建模

1. **层析构建**：按5层结构组织特征
2. **一致性检验**：确保各层特征一致
3. **置信度评估**：为每个特征评估置信度

### 第四步：输出生成

1. **结构化输出**：生成JSON格式的人格数据
2. **摘要生成**：生成可读的人格摘要
3. **验证检查**：检查数据完整性

## 质量保证

### 准确性保证

1. **多源验证**：从多个角度验证同一特征
2. **上下文考虑**：考虑对话上下文，避免误解
3. **时间维度**：考虑时间变化，识别稳定特征

### 完整性保证

1. **维度覆盖**：确保5个维度都有数据
2. **深度足够**：每个维度都有足够细节
3. **平衡性**：各维度数据量相对平衡

### 可用性保证

1. **可执行性**：生成的特征可以直接用于对话生成
2. **可理解性**：特征描述清晰易懂
3. **可修改性**：支持用户修正和补充

## 输出格式

最终输出一个完整的人格数据JSON对象，包含5个维度的详细数据，可以直接用于构建AI对话的系统提示词。
